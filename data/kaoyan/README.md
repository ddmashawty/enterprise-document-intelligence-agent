# 考研（硕士研招）信息种子数据包 · 广东四校泛计算机

这是给 `enterprise-document-intelligence-agent` 仓库用的**第一批考研种子数据**：官方原始文件、人工核对过的结构化结果（`majors.csv`）、机器可读的来源清单（`sources.json`）和文件校验清单（`raw/manifest.csv`）。

- 采集时间：2026-09-25（北京时间）；打包时间：2026-09-27
- 放到仓库的位置：**`data/kaoyan/`**（整个目录原样复制，包括隐藏文件 `.gitignore`）
- 用途：① 种子数据库（seed）；② 解析器 / 抽取器的测试夹具；③ Agent 问答的 golden 验收集；④ 爬虫适配器的站点结构参考

> 为什么放 `data/kaoyan/` 而不是 `data/raw/kaoyan/`：`data/raw/` 是现有 `POST /v1/ingest` 和 `scripts/ingest_demo.py` 的默认导入目录（企业演示语料）。放进去会在重构完成前把考研文件混进演示索引。仓库根 `.gitignore` 的 `data/raw/**/*.pdf` 规则管不到 `data/kaoyan/`，所以本包自带一个子目录 `.gitignore`（见下文“入库策略”）。

## 2. 年份口径（重要）

- 截至 2026-09-25，四校中**只有暨南大学发布了 2027 招生专业目录**（HTML，202607 版）。中大、华工、华师的 2027 简章 / 目录都**还没发布**，所以这三校的行用的是 **2026** 版。暨南 2027 简章也未发布。
- 所有“复试线”都是 **2026 年**的线（2027 考试还没考）。
- 华师 2027 推免目录（xls，2026-09-21）已发布，能提前看出变化：019 新出现 085410，推免目录里没有 085405。要等 2027 正式目录确认。
- Agent 回答时**必须写明数据年份**，不能把 2026 的数说成 2027 的。

## 3. 已知缺口

1. **华工目录拿不到**：`yanzhao.scut.edu.cn`（专业目录、学院复试方案、推免方案）从采集机访问会 302 到统一认证登录页。所以华工 081200 / 085404 / 083500 / 085405 的**总招生人数、推免数、初试科目都是空的**（`是否408` = “未知（目录不可达）”）。只有 140500 的科目来自一张通知图片。非官方聚合站说 081200 考 408，未采信。
2. **华工复试线是学校基本线**（08 工学 305/50/70，14 交叉学科 320/50/75），没找到学院公布的更高分数线。
3. **暨南 0812 按一级学科统筹**：2027 目录只给 0812 合计 24 人（含推免），二级学科行没有人数；2027 推免复试方案里 0812 合计推免 ≤19。暨南 2027 推免数多为“≤N”上限值。
4. **图片表格靠人工读图**：中大软件工程学院分数线 / 计划（png）、中大电子与通信学院分数线（HTML 内嵌 base64 图片）、华工校线（jpg）、华工 140500 初试科目（jpg）、华工 2027 科目调整（png）。
5. **扫描件未 OCR**：华工 2026 拟录取名单（不含推免）29MB / 113 页，没有文字层。
6. **口径冲突**（同一个“计划”有多个数，必须带口径）：中大目录计划 ≠ 学院复试细则“总计划”（724 的 081200：目录 9，细则 15）；华工“统考可用计划”（085404 为 21）≠ 学院通知“统考计划 35（含基地 / 联培）”；华师复试方案计划（041 的 085410 为 72）≠ 目录（66）。
7. **第三方数据有错**：iqihang 把中大 725 的 085405 推免 / 公开数（30 / 23）写反；某搜索摘要把华师 085404 复试线写成 288（实际 348，288 是退役大学生士兵计划线）。一律以官方为准。
8. 11 个文件在 `sources.md` 里没有记录来源页 URL，`sources.json` 中 `page_url` 为 `null`（有 WebPlus `article_id` 的已填上）。华工学费 PDF 页面上有两个同名附件链接，没记录下载的是哪个，两个候选 URL 都写在 `notes` 里。

## 4. `majors.csv` 字段说明

UTF-8 **带 BOM**（`encoding='utf-8-sig'` 读取）。所有列都是字符串，数字列里会混有文本，**解析时不要直接转 int**。

| 列 | 含义 | 取值 / 注意 |
|---|---|---|
| 学校 | 学校全称 | 中山大学 / 华南理工大学 / 暨南大学 / 华南师范大学 |
| 学院 | 院系，带院系代码前缀 | 如 `670计算机学院`；华工没有代码 |
| 专业代码 | 6 位专业代码 | 暨南有自设二级学科 `0812Z3` |
| 专业名称 | 专业名 | 华工 140500 名称里带“（交叉学科，学硕）” |
| 学位类型(学硕/专硕) | 学硕 / 专硕 | |
| 研究方向 | 目录中的方向 | 中大 `69 不分方向` 的 69 是方向代码；华工方向是从 2026 拟录取名单推出来的（已标注）；多方向用 `；` 分隔 |
| 学习方式(全日制/非全) | 全日制 / 非全日制 | |
| 拟招生人数(总) | **目录口径**总计划（含推免） | 空 = 未取得（华工）或不单列（暨南 0812 二级学科）。学院细则里的不同数字写在备注 |
| 其中推免人数 | 推免人数 | 数字；`≤N` = 上限值（暨南 2027 推免复试方案）；`（0812合计≤19）` = 一级学科合计；空 = 未知 |
| 考试科目1政治 / 考试科目2外语 / 考试科目3 / 考试科目4 | 初试科目（带代码） | 空 = 未知（华工）或没有统考（中大 083900 仅招推免）。暨南写作“408计算机学科专业基础综合” |
| 是否408 | 专业课是否 408 | 是 / 否 / `否（仅招推免）` / `未知（目录不可达）` |
| 2026复试线总分 | 2026 复试线总分 | 优先学院线；华工是学校基本线；空 = 无统考或未知 |
| 复试线单科(政治/外语/业务课) | 单科线 | 自由文本，如 `政治50/外语50/业务课一60/业务课二60` |
| 数据年份 | 计划 / 科目的年份 | `2026`、`2027（复试线为2026）`、`2027（仅推免目录）` |
| 来源URL | 官方来源 | 多个用 ` ; ` 分隔；个别里面夹着中文括号说明（华工目录被拦截），解析时要清洗 |
| 备注 | 口径说明与补充事实 | 学院细则计划、退役 / 少干专项计划及其线、复试 / 拟录取人数、第三方错误提醒等。**很多验收答案在这里** |

`majors.xlsx` 与 csv 内容相同（冻结首两列、开了筛选）。`scripts/build_majors.py` 能原样生成这两个文件（已验证逐字节一致），数值是硬编码的人工核对结果。

## 6. 入库策略（仓库是 public）

- **入库（69 个文件，约 10MB）**：README、CURSOR_PROMPT、majors、sources.*、manifest、scripts，以及**不含个人信息且 ≤3MB** 的原始文件（通知 HTML、目录 HTML、校线 / 学费 PDF、图片表格、华师 2027 推免 xls 等）。它们是解析器测试的好夹具。
- **只留本地（28 个，由 `data/kaoyan/.gitignore` 忽略）**：
  - 含考生姓名 / 考生编号 / 成绩的名单类文件（复试名单、复试结果、拟录取名单、推免名单；暨南各学院复试方案 xlsx、华师三个学院的复试方案 HTML 里也带名单）。虽然是官方公示，但放进公开仓库不合适（个人信息保护）。
  - 单文件 >3MB：中大 2026 专业目录 PDF（5.2MB）、华工拟录取扫描件（29MB，本身也含个人信息）。
- 需要这些文件时，按 `raw/manifest.csv` 的 `source_url` 重新下载，用 `sha256` 校验（公示期过后官方可能已撤下）。
- 使用名单类文件时只做**统计**（人数、分数区间），回答和导出里**不要输出任何考生个人信息**。

## 7. 怎么用（摘要，细节见 CURSOR_PROMPT.md）

1. 用 `majors.csv` 生成种子库（每个数值带来源、年份、口径），同时生成 golden 问答集。
2. 用新的多格式加载器把 `raw/` 下的文件导入检索库（元数据带 school / year / doc_type）。
3. 解析器的回归测试：从 `raw/` 里入库的文件解析出的数值，要和 `majors.csv` 对得上（例如中大 670 的 085404 复试线 379、暨大 052 的 085412 复试线 348）。
4. 爬虫适配器参考 `sources.json` 的 `schools[]` 和 `sources.md` 的爬虫笔记。
