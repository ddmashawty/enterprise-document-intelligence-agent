## 5. 解析难点（对 LangGraph + DeepSeek 文档抽取的影响）

1. **扫描 PDF**：华工 2026 拟录取名单（不含推免）29 MB / 113 页，没有文字层，必须 OCR（PaddleOCR / 表格 OCR）；其余 PDF 基本都是文字版（pdffonts 有字体）。
2. **图片表格**：华工校线（jpg）、华工未来技术学院 140500 初试科目（jpg）、华工 2027 科目调整（png）、中大软件工程学院分数线和计划（png）、中大电子与通信学院分数线（**HTML 内嵌 base64 data URI 图片**，普通爬虫下载 `<img src>` 时容易漏掉）。需要多模态模型或 OCR。本次这几张图都是人工读取的。
3. **合并单元格**：华工统考可用计划 PDF 学院列纵向居中合并；中大分数线 PDF 竖排“学/术/学/位”；暨南复试方案 xlsx 多行表头 + 合并单元格，而且同一 sheet 里混着 3 张表（方案 / 名单 / 专项名单），要按标题行切分；华师 2027 推免 xls 前 6 列纵向合并（要 ffill）。
4. **一格多值 / 换行**：中大目录的初试科目①②③④在同一格内换行；华师目录“48(17)”总数和推免写在一起、方向行写“同上”；华师拟录取汇总表的专业代码在格内换行；暨南推免 PDF 单元格文字被截断。
5. **口径不一致**（抽取时一定要带上来源和口径）：中大目录计划 ≠ 学院复试细则中的“总计划”（例如 724 的 081200 目录写 9，细则写 15）；华工“统考可用计划”（085404 为 21）≠ 学院通知的“统考计划 35（含基地 / 联培）”；华师复试方案计划（041 的 085410 为 72）≠ 目录（66）；暨南 0812 按一级学科统筹，二级学科没有单独人数；推免在暨南 2027 是“≤N”上限值。
6. **版面串行**：pdftotext -layout 下中大目录会把相邻学院的标题排在别的学院的专业行旁边，需要用 pdfplumber 按坐标 / 表格提取。
7. **附件发现**：WebPlus 学院站用 `pdfsrc` 播放器 div 而不是 `<a>`；附件用 UUID 文件名；中大分页链接指向错误路径；暨南部分栏目页是空的 / 返回 410；同一文章出现在多个栏目 ID 下。
8. **访问受限**：yanzhao.scut.edu.cn 整站走统一认证（302 登录）；研招网专业目录接口有签名 / 反爬。建议对这类站点用有头浏览器（Playwright）或手动导出，而不是硬爬。
9. **文件格式杂**：html、pdf、xlsx、xls（老 BIFF，需要 xlrd 或 libreoffice 转换）、doc / docx（双选志愿书之类表单，不含数据），加上 jpg / png。现有的 PDF + txt 管线至少要补 html 表格、xlsx / xls、图片 OCR 三种输入。
10. **第三方聚合站错误**：iqihang 把中大软件工程学院 085405 的推免 / 公开数（30 / 23）写反；某搜索摘要把华师 085404 线写成 288（实际 348，288 是退役计划线）；华工 081200 考 408 只见于非官方来源。**必须以官方为准**。
