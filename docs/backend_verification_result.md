## 年报召回优化与复测（同日）

**根因：** 纯稠密检索把问句打到审计/财报页；BM25 更能命中「主营业务分行业」「可能面对的风险」等章节原文。

**改动：**
- `hybrid`：dense + BM25 的 RRF 融合（`src/doc_agent/rag/store.py`）
- 查询扩展 / 文档名启发式过滤 / 意图短语加权（`query_expand.py`）
- `rag_search` 支持 `doc_name`，默认 `top_k=8`

**复测问句：**
`从茅台2024年报中概括主营业务和主要风险因素，用条目列出，并标注页码或来源片段。`

**结果：**
- citations 含 p9 / p15 / p22 / p56 等关键页
- 回答含茅台酒及系列酒、分产品/地区/渠道收入，以及四类风险（宏观/安全/舆情/环保）并标注页码
- 小瑕疵：风险条目的展开说明偶有同页上下文拼贴，名称与页码正确
